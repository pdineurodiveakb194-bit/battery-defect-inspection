# battery-defect-inspection
# 電極コーティング欠陥検査AIアプリ

## 概要

電極コーティング画像をAIで解析し、表面の欠陥を分類するWebアプリケーションです。

製造現場における外観検査の補助を想定し、画像ごとの判定結果とGrad-CAMによる可視化を提供します。

## 主な機能

- 画像の選択と一括判定
- 4種類の欠陥の分類
  - 割れ（Surface Crack）
  - 剥離（Delamination）
  - ピンホール（Pinhole）
  - その他の欠陥（Unclassified）
- 欠陥クラスごとの判定閾値の設定
- 判定結果の一覧表示
- Grad-CAMによる判定根拠の可視化
- ヒートマップ画像のZIPダウンロード

## 使用技術

- Python
- Streamlit
- PyTorch
- torchvision
- ConvNeXt-Tiny
- Pillow
- Matplotlib

## 使用方法

1. Webアプリを開きます。
2. 判定したい電極コーティング画像を選択します。
3. 各欠陥クラスの判定閾値を設定します。
4. 判定を実行します。
5. 判定結果を確認し、必要に応じてGrad-CAM画像を生成・ダウンロードします。

## 実行方法

Python環境に必要なライブラリをインストールしたうえで、以下のコマンドを実行します。

```bash
streamlit run app.py
```

必要なライブラリやバージョンは、プロジェクトの依存関係ファイルを参照してください。

## 学習済みモデル

本アプリは学習済みの画像分類モデルを使用します。

実行時には、設定された保存先からモデルファイルを取得できる必要があります。モデルの配置方法や取得に必要な設定については、実際の実装に合わせて記載してください。

## 注意事項

本アプリの判定結果はAIによる推定です。実際の製造工程への適用にあたっては、対象設備・画像条件に応じた性能検証と、人による確認を行ってください。
